# AGRITRUST – Cold-Chain Intelligence Platform

AI-Assisted Agricultural Supply Chain Monitoring and Loss Prevention

## About the Project

AGRITRUST is a cold-chain intelligence platform designed to improve transparency and traceability across the agricultural supply chain. It helps monitor shipment conditions, identify potential spoilage risks, and support evidence-based investigation of quality and quantity discrepancies.

## Key Features

- Shipment Tracking – Monitor shipment status and movement.
- Cold-Chain Monitoring – Track temperature and humidity using available or simulated telemetry.
- Risk Alerts – Identify abnormal conditions that may increase spoilage risk.
- Digital Evidence – Maintain shipment, inspection, and quantity records.
- Loss Prevention – Support early intervention and investigation of shipment discrepancies.
- Supply-Chain Transparency – Improve coordination between farmers, logistics providers, cold-storage operators, and buyers.

## Technology Stack

- Frontend: React, Vite
- Backend: Python, FastAPI
- Database: PostgreSQL
- Tools: Git, GitHub

## Project Workflow

Shipment Registration → Physical Verification → Dispatch → Condition Monitoring → Delivery Verification → Investigation
